# dotfiles

here are my dotfiles for fedora + niri.

## Install

1. Clone the repo:
   ```sh
   git clone https://github.com/samuelzubin/dotfiles ~/dotfiles
   cd ~/dotfiles
   ```

2. Run the install script:
   ```sh
   ./install.sh --system
   ```

3. Log out and pick **niri** on the login screen.


Note: Anything already in the way gets moved to `~/.dotfiles-preinstall-<timestamp>/`, so nothing is overwritten.
