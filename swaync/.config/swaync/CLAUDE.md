# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

Personal SwayNC (Sway Notification Center) configuration directory — not a software project.
There is no build, lint, or test tooling; changes are config/CSS edits applied by reloading
the running swaync daemon.

## Files

- `config.json` — main config (behavior, timeouts, layout, widgets, widget-config). Validated
  against `configSchema.json` via its `$schema` key.
- `colors.css` — Material You color tokens, generated by Matugen. Do not hand-edit; it gets
  regenerated/overwritten. Change the color scheme upstream (Matugen), not here.
- `style.css` — hand-written GTK CSS for actual visual styling. Imports `colors.css` and
  references its `@define-color` tokens (e.g. `@primary`, `@surface_container_high`). This is
  where styling customizations belong.
- `configSchema.json` — JSON schema for `config.json`, used only for editor validation/
  autocomplete. Not a file to edit for behavior changes.

## Applying changes

After editing `config.json` or `style.css`, reload swaync rather than restarting it:
- `swaync-client -rs` — reload style (CSS) only
- `swaync-client -R` — reload config
- `swaync-client -t` — toggle the control center panel, useful for visually checking changes

## Notes on config.json structure

- `widgets` (array) controls which widgets appear in the control center and their order;
  `widget-config` holds per-widget settings keyed by widget name.
- The `buttons-grid` widget's `actions` each define a `command` and `update-command` shell
  snippet; toggle-type actions read `$SWAYNC_TOGGLE_STATE` to decide which branch to run (see
  the existing Wi-Fi/Bluetooth toggles for the pattern).
- Notification styling in `style.css` is split by urgency via GTK style classes:
  `.notification.low`, `.notification.normal`, `.notification.critical`.
